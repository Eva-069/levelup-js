# Рівні складності · стежка крізь JavaScript

Вебзастосунок для гейміфікації курсу JavaScript у стилі туманного карельського лісу.
Користувач проходить стежку з 6 глав-локацій, розв'язує задачі з кодом і квізи, здобуває XP, зірки,
ягоди, досягнення і бореться з хранителями (босами) наприкінці кожної глави.

## Можливості

- **Глави-локації:** Узлісся → Лабіринт умов → Річка циклів → Озерний край → Сейди → Вершина + таємна стежка.
- **Хранителі:** остання задача глави — бос; перемога відкриває наступну главу.
- **Перевірка коду на сервері:** XP нараховується лише після того, як сервер сам прожене тести.
- **Захист від зависань:** нескінченний цикл зупиняється (2 с у браузері, 1 с на сервері).
- **Зірки:** 3 без підказок, 2 з однією, 1 з двома. Підказки відкриваються через сервер.
- **Секундомер і рекорди** для кожного квесту.
- **Квізи** з вибором відповіді (правильна відповідь не передається в браузер).
- **Щоденний виклик** — бонус лише за реальне рішення задачі.
- **Ягоди і крамниця:** рамки аватара, титули, теми оформлення (лише косметика).
- **4 теми:** Карелія, Білі ночі, Північне сяйво, Осіння тайга.
- **Редактор коду** з підсвіткою, номерами рядків, Tab і автовідступом.
- **Профіль:** календар активності за 12 тижнів, прогрес глав, виконані квести.
- **Рейтинг** за тиждень і за весь час; серія днів, комбо, 17 досягнень.

## Технології

Node.js, Express, MongoDB (Mongoose), JWT, bcryptjs; фронтенд — HTML, CSS, JavaScript без фреймворків.

## Запуск

    npm install
    cp .env.example .env    # і впиши свої MONGODB_URI та JWT_SECRET
    npm run dev

Відкрити: http://localhost:3000

## Структура

    data/gameData.js      — рівні, глави, квести, досягнення, товари крамниці
    middleware/auth.js    — перевірка JWT
    models/User.js        — модель користувача і прогресу
    routes/auth.js        — реєстрація і вхід
    routes/quests.js      — квести, підказки, перевірка рішень, рейтинг
    routes/shop.js        — крамниця
    utils/progress.js     — XP, рівні, серія, комбо, блокування глав
    utils/runTests.js     — запуск тестів коду на сервері
    public/               — index.html, style.css, app.js, worker.js

> Примітка: серверна перевірка коду використовує модуль `vm` з обмеженням часу. Для навчального
> проєкту цього достатньо, але це не повна «пісочниця» для публічного сервісу.
